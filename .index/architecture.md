# Architecture

**What this is.** A design system for Diamaco Growth extracted from the live site (diamacogrowth.co.za, read 2026-10-12),
laid out in the claude.ai/design design-system project format and pushed to the project **DIAMACO GROWTH**
(`83a45216-2447-4a7d-ba71-1a38cad57973`) via the DesignSync tool.

**Layers.**
1. `tokens/*.css` — CSS custom properties (site `:root` names kept) + text-style classes. `styles.css` imports all.
2. `components/components.css` — class-based component styles (`dg-*`); needed for pseudo-element effects (button sweep,
   card sheen, underline draw).
3. `components/<group>/<Name>.jsx` — React 18 function components that only apply `dg-*` classes; relative imports with
   `.jsx` extensions; named exports only. Each has `.d.ts` (props contract) and `.prompt.md` (usage).
4. Specimen cards (`components/**/*.card.html`, `guidelines/*.html`) — first line `<!-- @dsCard group name viewport subtitle -->`;
   component cards load React/ReactDOM/Babel from unpkg (SRI-pinned) + `../../_ds_bundle.js` and read
   `window.DIAMACOGROWTH_83a452`.
5. `ui_kits/website/` — screens composed only from components; loaded by its own `kit-loader.js` (fetch + Babel), not the bundle.

**Generated assets (regenerate, don't hand-edit):** `components/brand/Logo.jsx` (from `assets/logos/*.svg`),
`assets/icons/*.svg` (from `Icon.jsx`), `assets/social/*.jpg` (from `ui_kits/social/render.html`). Generators live in
`tools/brand-assets/` (git only, not uploaded to claude.ai/design); see its README for the command sequence.

**Generated by claude.ai/design on its side (never written from here):** `_ds_bundle.js`, `_ds_manifest.json`,
`_adherence.oxlintrc.json`, thumbnails.

**Local verification loop.** `ds-preview` server → headless Chrome screenshots (scratchpad `shoot.ps1`, fresh profile per
shot) → contact sheets. Card viewports were sized from measured body heights.

**Constraints.** Dark theme only; red is the single accent; no invented proof (testimonials, client counts); phone/WhatsApp
numbers are placeholders (POPIA minimisation).
